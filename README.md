
# koishi-plugin-maichuni-scorehelper

舞萌中二节奏分数查询的相关功能插件。

## 使用方法

1. 部署登录页面（可选，见下文）
2. 在 Koishi 插件配置中设置 AUTH_TOKEN（必须与登录页面一致）与水鱼开发者令牌（可选）与落雪开发者令牌。

注意：配置登陆页面和水鱼开发者令牌两者二选一，如果您都未选择，则只能使用落雪源的数据与相关功能。

## 部署登录页面

1. Fork本仓库的`page`分支
2. 查看该分支中的README.md，选择部署平台并按照步骤操作。
